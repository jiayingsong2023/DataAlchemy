# GA-01 真实试点包

本包在 Phase 4 发布候选通过后使用；它不是内部 Alpha 或模拟预演的替代品。

每支设计合作团队需要提供：独立 tenant、仅只读的服务账户、5--10 项真实任务、数据
处理边界、成功阈值、业务负责人和安全联系人。禁止使用个人管理员令牌或将原始资料提交
到本仓库。

每周至少抽检 10 项任务，记录任务 ID、来源 URI/版本、ACL 判定、工具及审批事件、恢复
事件、人工接管、延迟和用户确认。任何跨 tenant、越权工具或记忆泄漏立即暂停扩大使用。

四周后由双方签署：任务价值、完成率、恢复率、人工接管率、事件数及遗留风险。只有该
签署完成后才关闭 GA-01 并批准正式生产发布。
