# 文档归档

此目录保留决策依据、阶段计划、验收记录以及旧 K3d/Spark 操作资料，供追溯使用；它们不构成
当前发布候选的支持或部署承诺。

- `assessments/`：产品、技术与早期路线评估。
- `roadmap/`：已完成阶段的路线图与改进计划。
- `phases/`：Phase 1--4 的设计、计划与历史退出报告。
- `legacy-k3d-spark/`：旧环境安装、排障、测试和演示资料。

当前用户应从 [架构](../ARCHITECTURE.md)、[一份文档的内部试点快速开始](../PILOT_QUICKSTART.md)
和[发布状态](../RELEASE_STATUS.md)开始。
